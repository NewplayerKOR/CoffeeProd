## 수치·출처 확인

- 보관 증빙 641개 파일의 SHA-256을 원래 보관 manifest와 대조했다.
- 원래 생성 코드가 측정 자료에서 추출한 비교표 21행과 포트폴리오 데이터를 대조했다.
- QA9의 완료된 HTTP 46세션(before 39, after 7)의 압축 JSONL을 읽고 요청별 업무 시간에서 p95를 독립 재계산해 native summary와 대조했다. 중단된 세션은 포함하지 않았다.

- 코드 설명의 파일·앵커·행 번호와 현재 소스를 연결했다. 과거 측정 revision과 현재 JDK·프레임워크를 같은 실험으로 취급하지 않는다.
- 최신 실행 결과는 [validation.json](data/validation.json), 이미지별 출처와 해시는 [portfolio.json](data/portfolio.json) 및 [figure-manifest.json](data/figure-manifest.json)에 기록한다.

## 이미지·문서 확인

- 원본 PNG 10장을 각각 열어 한글·값·단위·축·범례·설명·표현 범위를 확인했다.
- 960×720 PNG 10장을 각각 열어 축소 가독성을 확인했다. 원본 파일은 2400×1800이며 이미지 열람 도구는 큰 이미지를 화면에 맞춰 표시할 수 있다.
- 모든 텍스트의 이미지 경계와 텍스트 사이 겹침을 생성 시 검사했다. 글꼴 누락도 오류로 처리했다.
- 자동 경계 검사에서 발견한 하단 문구 및 추천 그래프 간격 문제를 수정했다. 시각 확인에서 장바구니 관측 범위 선과 수치 라벨의 겹침을 발견해 라벨을 범위 밖으로 옮겼다.
- 회색 적용 전·청록 적용 후·갈색 비용 증가에 직접 라벨과 수치를 함께 써서 색만으로 의미를 구분하지 않도록 했다. 0개 로딩도 명시적으로 표시했다.
- 한국어 설명·UTF-8·로컬 Markdown 링크·이미지 크기·해시를 확인했다.
- 이미지별 실제 시각 확인과 파일 해시는 [visual-review.json](data/visual-review.json)에 별도 기록한다. 재생성 후 이미지 해시가 바뀌면 시각 확인도 다시 해야 한다.
