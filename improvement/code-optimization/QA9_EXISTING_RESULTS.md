## 2. HTTP 비교에 사용한 완료 원본

홈서버 전용 Docker Backend/PostgreSQL16/Redis7/mock PG에 로컬 PC가 LAN HTTP로 요청했다. 운영 서비스·실제 PG·R2 전송·Cloudflare 경로는 측정 대상에 넣지 않았다. 일반회원10,000명·주문150,000건·주문상품375,000건·카탈로그192개의 동일V18 스냅샷을 사용하고 개선 후에는V19를 적용했다.

비교 소스는 전체 개선 전 `b04bf9e`와 개선 후 `008d443`다. 측정기 해시는 `6d63b7f073649f1804950bbf2a87dc3d77fa696f58aee363eb49f0009dfa7057`, fixture 해시는 `f9506ef0ae7f727d96eb465706d2e2ac9054f9de83afdd039299a75817c9fabd`다. 각 HTTP 세션은 복원→예열30초→같은 앱의 본 측정이며 일반 조회는10업무회/s·2분이다.

추천의 decaf null/true/false·limit5/10에 대한 전체 결과를 두 규모/3회씩 대조해 점수·이유·순서 등 golden 일치를 확인했다. 서비스 진단의 엔티티·컬렉션 수는 ORM 로딩 전체 합이며 HTTP 요청 전체의 로딩 수와 구분한다.
