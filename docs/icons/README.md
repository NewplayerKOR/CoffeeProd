| 파일 | 출처 |
| --- | --- |
| [toss.png](toss.png) | [Toss Payments 개발자센터](https://docs.tosspayments.com/)에서 사용하는 [공식 파비콘](https://static.toss.im/tds/favicon/favicon-196x196.png) |
| [h2.png](h2.png) | [H2 공식 사이트](https://www.h2database.com/html/main.html)의 [H2 로고](https://www.h2database.com/html/images/h2-logo-2.png) |

Toss·H2 이미지의 출처는 Devicon과 구분한다. 표시 크기만 지정하고 원본 로고 파일은 유지했다. BCrypt처럼 독립된 제품 로고가 없는 알고리즘과 내부 Fake Gateway는 기술명으로 표시한다.

## 표시용 복사본

[gradle-display.svg](gradle-display.svg)와 [github-display.svg](github-display.svg)는 각각 원본 SVG를 밝은 바탕 위에 배치한 표시용 복사본이다. 어두운 화면에서도 로고 형태를 읽을 수 있도록 바탕과 여백만 추가했다. 원본 색상·도형과 라이선스는 유지한다.
